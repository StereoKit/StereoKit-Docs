# struct UISettings

Visual properties and spacing of the UI system.

## Instance Fields and Properties

|  |  |
|--|--|
|float [backplateBorder]({{site.url}}/preview/Pages/StereoKit/UISettings/backplateBorder.html)|How wide is the back-border around the UI elements, in meters.|
|float [backplateDepth]({{site.url}}/preview/Pages/StereoKit/UISettings/backplateDepth.html)|How far up does the white back-border go on UI elements? This is a 0-1 percentage of the depth value.|
|float [depth]({{site.url}}/preview/Pages/StereoKit/UISettings/depth.html)|The Z depth of 3D UI elements, in meters.|
|float [gutter]({{site.url}}/preview/Pages/StereoKit/UISettings/gutter.html)|Spacing between sibling items, in meters.|
|float [margin]({{site.url}}/preview/Pages/StereoKit/UISettings/margin.html)|The margin is the space between a window and its contents, in meters.|
|float [padding]({{site.url}}/preview/Pages/StereoKit/UISettings/padding.html)|Spacing between an item and its parent, in meters.|
|float [rounding]({{site.url}}/preview/Pages/StereoKit/UISettings/rounding.html)|Radius of the UI element corners, in meters.|
|float [separatorScale]({{site.url}}/preview/Pages/StereoKit/UISettings/separatorScale.html)|Defines the scale factor for the separator's thickness. The thickness is calculated by multiplying the height of the text by this factor. The default value is 0.4.|
