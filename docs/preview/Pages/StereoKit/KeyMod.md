# enum KeyMod

A bit flag describing which of the keyboard's modifier keys are held.

## Enum Values

|  |  |
|--|--|
|Alt|Either alt key.|
|Cmd|Either Windows/Mac Command key.|
|Ctrl|Either ctrl key.|
|None|No modifier keys are held.|
|Shift|Either shift key.|
