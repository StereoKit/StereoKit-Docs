# [RenderSettings]({{site.url}}/preview/Pages/StereoKit/RenderSettings.html).materialVariant

<div class='signature' markdown='1'>
int materialVariant
</div>

## Description
Specifies which Material variant should be used for
rendering. 0 is the normal default material, any others will
generally be application-defined by setting up each Material's
Variant with specific shaders. If a Material has no corresponding
variant, it will not be drawn.
