# [Interaction]({{site.url}}/preview/Pages/StereoKit/Interaction.html).DefaultDraw

<div class='signature' markdown='1'>
static bool DefaultDraw{ get set }
</div>

## Description
By default, StereoKit will draw indicators for some of the
default interactors, such as the far interaction / aiming rays.
This doesn't affect custom interactors. Setting this to false will
prevent StereoKit from drawing any of these indicators.
