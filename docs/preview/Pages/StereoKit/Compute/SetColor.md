# [Compute]({{site.url}}/preview/Pages/StereoKit/Compute.html).SetColor

<div class='signature' markdown='1'>
```csharp
void SetColor(string name, Color colorGamma)
```
Set a color parameter by name! Color is converted
from gamma to linear space, so what the shader receives will
be in linear. If you're working in linear already, use
SetVector with a Vec4 instead!
