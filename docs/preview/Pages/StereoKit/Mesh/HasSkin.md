# [Mesh]({{site.url}}/preview/Pages/StereoKit/Mesh.html).HasSkin

<div class='signature' markdown='1'>
bool HasSkin{ get }
</div>

## Description
Indicates whether this Mesh has CPU skinning data
attached. A Mesh gains skin data when SetSkin is called, or
when it's loaded from a skinned glTF.
