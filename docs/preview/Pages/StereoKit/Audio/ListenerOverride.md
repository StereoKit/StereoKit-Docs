# [Audio]({{site.url}}/preview/Pages/StereoKit/Audio.html).ListenerOverride

<div class='signature' markdown='1'>
static Nullable`1 ListenerOverride{ get set }
</div>

## Description
Normally the audio listener follows the user's head.
Set this to hear the scene from somewhere else - a third person
camera, or a remote avatar - and set it to null to give the ears
back to the head.
