# [Renderer]({{site.url}}/preview/Pages/StereoKit/Renderer.html).SetFOV

<div class='signature' markdown='1'>
```csharp
static void SetFOV(float verticalFieldOfViewDegrees)
```
Only works for 2D windowed modes! This updates the
camera's projection matrix with a new vertical field of view.

This value only affects perspective mode projection, which is the
default projection mode.
</div>

|  |  |
|--|--|
|float verticalFieldOfViewDegrees|Vertical field of view in degrees.|
