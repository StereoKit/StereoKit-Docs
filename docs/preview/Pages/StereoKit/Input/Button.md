# [Input]({{site.url}}/preview/Pages/StereoKit/Input.html).Button

<div class='signature' markdown='1'>
```csharp
static BtnState Button(InputButton buttonType)
```
Gets a binary button state from the input system. These
are on/off inputs like controller face buttons and thumbstick
clicks.
</div>

|  |  |
|--|--|
|[InputButton]({{site.url}}/preview/Pages/StereoKit/InputButton.html) buttonType|The type of button input to retrieve.|
|RETURNS: [BtnState]({{site.url}}/preview/Pages/StereoKit/BtnState.html)|A BtnState describing whether the button is active, just became active, or just became inactive this frame.|
