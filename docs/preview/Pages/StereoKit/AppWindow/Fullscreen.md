# [AppWindow]({{site.url}}/preview/Pages/StereoKit/AppWindow.html).Fullscreen

<div class='signature' markdown='1'>
bool Fullscreen{ get }
</div>

## Description
Is this window currently covering its whole display? This
is always the window's real state, so it also picks up fullscreen
changes the user made through the window manager. Use
RequestFullscreen to change it.
