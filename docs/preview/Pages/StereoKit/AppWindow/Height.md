# [AppWindow]({{site.url}}/preview/Pages/StereoKit/AppWindow.html).Height

<div class='signature' markdown='1'>
int Height{ get }
</div>

## Description
The height of the window's drawable area, in physical
pixels. This is the size the swapchain renders at, and it changes
whenever the window is resized.
