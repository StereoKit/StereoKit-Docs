# [AppWindow]({{site.url}}/preview/Pages/StereoKit/AppWindow.html).Width

<div class='signature' markdown='1'>
int Width{ get }
</div>

## Description
The width of the window's drawable area, in physical
pixels. This is the size the swapchain renders at, and it changes
whenever the window is resized.
